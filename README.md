# azrabegzadic.github.io

Personal website of Azra Begzadić. A single static page, no build step.

- `index.html`: all content (bio, links, publications)
- `css/style.css`: layout, colors and font sizes
- `assets/`: profile picture and other files

To add a publication, copy the commented `<li class="pub">` block in `index.html` into the publications list.

The layout is based on Start Bootstrap's Simple Sidebar (MIT). It uses Bootstrap 3.3.7 (MIT), Font Awesome Free 5.8.1 (icons CC BY 4.0, fonts SIL OFL 1.1) and the Lato font (SIL OFL 1.1).
